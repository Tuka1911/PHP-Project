# PHP Project — Jinal іс-шаралар платформасы

**PHP 8.2 және MySQL/MariaDB** арқылы жасалған оқу веб-қосымшасы. Jinal қалалық іс-шараларды табуға, қатысуға жазылуға және өз іс-шараларыңды ұйымдастыруға көмектеседі.

## XAMPP арқылы іске қосу

1. XAMPP панелінде **MySQL → Start** батырмасын басыңыз.
2. Жоба қалтасында PowerShell ашып, орындаңыз:

   ```powershell
   .\start.ps1
   ```

Скрипт PHP-ді табады, `jinal` дерекқорын дайындайды және **http://127.0.0.1:8088/** мекенжайын браузерде ашады. Бұл нұсқа XAMPP құрамындағы PHP серверін пайдаланады; Apache міндетті емес. Скрипт сервердің PID нөмірін және оны тоқтату командасын көрсетеді. Қосымшаны пайдаланғанда MySQL қосулы болуы керек.

PowerShell скрипттеріне шектеу қойылса, жүйе саясатын өзгертпей, командаларды қолмен орындаңыз:

```powershell
C:\xampp\php\php.exe scripts\setup.php
C:\xampp\php\php.exe -S 127.0.0.1:8088 -t public
```

Браузерде http://127.0.0.1:8088/ мекенжайын ашыңыз. Қолмен іске қосылған сервер **Ctrl+C** арқылы тоқтайды.

## Мүмкіндіктер

- Атауы мен сипаттамасы бойынша іздеу; санат, қала және күн бойынша сүзу; сұрыптау мен беттерге бөлу.
- Іс-шараның күні, мекенжайы, бағасы және бос орындары көрсетілген жеке беті.
- Тіркелу, кіру, шығу және PHP сессиялары.
- Өз іс-шараларыңды құру, көру, өңдеу және жою — толық CRUD.
- Іс-шараға жазылу, жазылудан бас тарту және жеке кабинет.
- Пікірлер және профильді өңдеу.
- Қазақша, орысша және ағылшынша интерфейс; тіл таңдауы есте сақталады.
- Бейімделетін дизайн, жергілікті SVG иллюстрациялары және интерфейс анимациялары.
- PDO дайындалған сұраныстары, серверлік валидация, XSS-тен қорғау, CSRF токендері және құқықтарды тексеру.
- Email мен IP жұбы үшін 15 минутта бес сәтсіз кіру әрекетінен кейін уақытша шектеу.

Пайдаланушылар жазған іс-шара атаулары, сипаттамалар, есімдер мен пікірлер бастапқы тілінде қалады; интерфейстің тілін ауыстыру оларды автоматты аудармайды. Көрсетілген баға ақпараттық сипатта: сайтта онлайн төлем жоқ.

## Дерекқор баптаулары

Әдепкі XAMPP параметрлері: `127.0.0.1:3306`, пайдаланушы `root`, бос құпиясөз, дерекқор `jinal`.

Басқа сервер үшін `DB_HOST`, `DB_PORT`, `DB_NAME`, `DB_USER`, `DB_PASS` орта айнымалыларын орнатыңыз немесе Git елемейтін `config.local.php` файлын жоба түбірінде жасаңыз:

```php
<?php
return [
    'host' => '127.0.0.1',
    'port' => 3306,
    'name' => 'jinal',
    'user' => 'root',
    'password' => '',
];
```

Басымдық: **орта айнымалылары → `config.local.php` → әдепкі мәндер**. `.env.example` — параметрлер үлгісі; `.env` файлын автоматты оқу қарастырылмаған. Нақты құпиясөздерді Git-ке қоспаңыз.

`scripts/setup.php` тек командалық жолдан орындалады. Қайта іске қосу бұрынғы деректерді жоюға арналмаған. Сессиялар қосымша жасайтын `.runtime/sessions` қалтасында, `public/` сыртында сақталады. `.runtime/` және `runtime/` Git-ке кірмейді.

| Бет | Маршрут | Қолжетімділік |
| --- | --- | --- |
| Басты бет | `index.php?page=home` | Барлығына |
| Афиша | `index.php?page=events` | Барлығына |

| Құру / өңдеу | `index.php?page=edit` / `edit&id=1` | Құқықтарына сәйкес |

| Жоба туралы | `index.php?page=about` | Барлығына |

`public/index.php` — негізгі кіру нүктесі. Беттер GET арқылы таңдалады, деректерді өзгертетін әрекеттер POST арқылы орындалады.

```text
app/                  PHP логикасы, PDO, сессиялар, аударма сөздіктері
app/translations/     қазақша және ағылшынша интерфейс мәтіндері
database/             MySQL кестелерінің SQL схемасы
docs/                 ER-диаграмма, есептер, тест жоспары және қорғау
public/               жария каталог: index.php, CSS, JS, SVG
scripts/setup.php     схема мен көрсетілім деректерін CLI арқылы орнату
templates/            бет үлгілері және ортақ бөліктер
tests/integration.php HTTP және дерекқор арқылы функционалдық тексеру
tests/languages.php   интерфейс тілдерін тексеру
start.ps1             жергілікті іске қосу және браузерді ашу
```

## Тексеру

**2026 жылғы 18 қарашада** PHP 8.2.12 және MariaDB 10.4.32 ортасында, `http://127.0.0.1:8088/` мекенжайында **43 интеграциялық және 38 тілдік тексеру — барлығы 81 тексеру сәтті өтті**. Қосымша жұмыс істеп тұрғанда:

```powershell
C:\xampp\php\php.exe tests\integration.php http://127.0.0.1:8088
C:\xampp\php\php.exe tests\languages.php http://127.0.0.1:8088
```

Бірінші тест авторизацияны, CRUD, жазылу/бас тартуды, іздеу мен сүзгілерді, құқықтарды, CSRF, XSS және кіру шектеуін тексереді. Екінші тест үш тілдегі беттерді, тіл cookie-файлын және динамикалық мәтіндерді тексереді. Нақты нәтижені командалар шығарған қорытындыдан қараңыз. Екі тестке де PHP cURL керек; CLI мен веб-қосымша бір дерекқор баптауларын пайдалануы тиіс. Интеграциялық тест тек өзінің бірегей деректерін жасап, соңында тазартады.

PHP синтаксисін тексеру:

```powershell
Get-ChildItem -Recurse -Filter *.php | ForEach-Object {
    & C:\xampp\php\php.exe -l $_.FullName
    if ($LASTEXITCODE -ne 0) { throw $_.FullName }
}
```

Мобильді интерфейстің браузердегі визуалды тексеруі бөлек орындалуы тиіс. Толық сценарийлер [тест жоспарында](docs/TEST_PLAN.md) берілген.

## Апталық жұмыс және академиялық адалдық

Тапсырма бойынша әр аптада кемінде үш мағыналы коммит қажет. Есептерге тек өзіңіз орындаған жұмыс пен нақты коммит сілтемелерін енгізіңіз. Бүгін жасалған жоба өткен сегіз аптадағы жұмысты дәлелдемейді; жалған күндер мен ойдан шығарылған тарих жасамаңыз.

Қорғаудан бұрын кодты түсініп, өз талаптарыңызға бейімдеңіз. PDO, сессия, GET/POST, кестелер байланысы мен құқықтарды тексеруді түсіндіре біліңіз. Жасанды интеллект көмегін курс ережесіне сәйкес көрсетіңіз.
