# Apache және PHP/MySQL хостингіне орналастыру

Бұл — жариялауға арналған нұсқаулық. Қосымша әзірге интернет-хостингке орналастырылған жоқ. GitHub репозиторийі бастапқы кодты сақтайды; PHP/MySQL қосымшасын іске қосу үшін бөлек хостинг қажет.

## XAMPP және Apache

README-дегі негізгі нұсқа PHP серверін 8088 портында іске қосады. Apache арқылы ашу үшін:

1. Қажет болса, жобаны өзіңіз `C:\xampp\htdocs\jinal` қалтасына көшіріңіз.
2. XAMPP-та Apache және MySQL қосыңыз.
3. `C:\xampp\php\php.exe C:\xampp\htdocs\jinal\scripts\setup.php` орындаңыз.
4. `http://localhost/jinal/public/` мекенжайын ашыңыз.

Дұрыс конфигурацияда жеке виртуалды хосттың `DocumentRoot` мәні `jinal/public` қалтасын көрсетеді. Сонда `app`, `database`, `scripts` және құпия баптаулар жария каталогтан тыс қалады. Қызметтік файлдардың HTTP арқылы ашылмайтынын тексеріңіз.

## Қашықтағы хостинг

PHP 8.2+, `pdo_mysql`, MySQL/MariaDB, сессиялар және HTTPS қажет. Нақты тариф пен шектеулерді провайдерден тексеріңіз. `php -S` — жергілікті әзірлеу сервері; хостингте провайдердің веб-сервері қолданылады.

1. Жеке дерекқор мен қажетті ең аз құқықтары бар пайдаланушы жасаңыз. Провайдер база атауына префикс қосуы мүмкін.
2. Нақты реквизиттерді орта айнымалыларына немесе жария каталогтан тыс `config.local.php` файлына жазыңыз.
3. Кодты `.git`, `.runtime`, `runtime` және жергілікті құпия файлдарсыз жүктеңіз. Жария түбір ретінде `public/` таңдаңыз.
4. SSH/CLI және құқықтар қолжетімді болса, `scripts/setup.php` іске қосыңыз. `CREATE DATABASE` тыйым салынса, дайын базаға `database/schema.sql` файлын phpMyAdmin арқылы импорттаңыз. Одан кейін интерфейсте пайдаланушы тіркеп, іс-шаралар құрыңыз. Орнату скриптін ашық HTTP бетіне айналдырмаңыз.
5. Ашық қолжетімділікке дейін көрсетілім аккаунттарын ауыстырыңыз немесе жойыңыз.
6. HTTPS пен session-cookie параметрлерін тексеріңіз. Техникалық қателерді келушіге шығармай, жабық журналға жазыңыз.

Провайдер `public/` қалтасын түбір етуге мүмкіндік бермесе, оның мазмұнын веб-түбірге, ал серверлік қалталарды сыртқа орналастырып, `require` жолдарын саналы түрде жаңартыңыз. Мұндай өзгерістен кейін тексерулерді қайталаңыз.

## Жарияланған нұсқаны тексеру

- HTTPS мекенжайын жеке терезеде және басқа құрылғыдан ашу.
- CSS, JavaScript және SVG жолдарын тексеру.
- Тіркелу, кіру, шығу және сессияны тексеру.
- Өз тест іс-шарасын құру, өзгерту және жою.
- Жазылу, бас тарту, іздеу, сүзгілер мен пагинацияны тексеру.
- Үш тілдің жұмысын және тіл таңдауының сақталуын тексеру.
- Құпия конфигурация, SQL, журналдар және `.git` қолжетімсіз екенін тексеру.
- Қонақтың жабық беттерге және бөтен пайдаланушының өңдеуіне рұқсат жоқтығын тексеру.
- Қателерде құпиясөз, SQL немесе шақыру стегі шықпайтынын тексеру.
