# Функционалдық тексеру жоспары

Тексерулерді жергілікті немесе бөлек тест дерекқорында орындаңыз. Жою әрекеттерінде тек өзіңіз жасаған тест деректерін қолданыңыз. Төмендегі тізім — жоспар; «өтті» белгісі нақты нәтижеден кейін қойылады.

**2026 жылғы 18 қарашадағы нәтиже:** PHP 8.2.12 және MariaDB 10.4.32 ортасында, `http://127.0.0.1:8088/` мекенжайында 43 интеграциялық және 38 тілдік тексеру — барлығы 81 тексеру сәтті өтті. Интеграциялық тест нақты HTTP сұраныстарын жіберіп, өзгерістерді дерекқормен салыстырады; профильдегі пайдаланушы мәтінінің қауіпсіз шығуы да тексеріледі. Бұл мобильді интерфейстің визуалды тексеруін алмастырмайды.

## Автоматты тексерулер

Қосымша іске қосулы кезде жоба түбірінен орындаңыз:

```powershell
C:\xampp\php\php.exe tests\integration.php http://127.0.0.1:8088
C:\xampp\php\php.exe tests\languages.php http://127.0.0.1:8088
```

PHP cURL және қосымшамен бірдей дерекқор баптаулары қажет. Бірінші тест бірегей тест жазбаларын жасайды және соңында тек соларды тазартады. Екінші тест үш тілдегі беттерді, cookie арқылы тілдің сақталуын, динамикалық мәтіндер мен сүзгі мәндерін тексереді. Нақты санын және нәтижесін әр команданың соңғы жолынан қараңыз. Синтаксис бөлек README командасымен тексеріледі.
